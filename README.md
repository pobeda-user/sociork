# Sociork — социальная сеть на карте

Android-приложение (Kotlin + Jetpack Compose) с картой Yandex MapKit, обменом геолокацией
между друзьями и точками-метками (магазин, точка сбора, дом, кафе). Backend — лёгкий
сервер на чистом Python (стандартная библиотека, без pip-зависимостей).

> распространение без письменного разрешения автора запрещено. Подробнее — в [`LICENSE`](LICENSE).

## Структура проекта

```
app/       — Android-приложение (Kotlin, Jetpack Compose, Yandex MapKit, Retrofit)
server_py/ — Backend-сервер на чистом Python (SQLite, HTTP API, раздача APK)
bucket-site/ — Web-версия (PWA), загружается в облачный бакет
```

## Что реализовано

- ✅ Соглашение об обработке персональных данных (152-ФЗ) — обязательный первый экран, без него регистрация невозможна (сервер также проверяет флаг `consentAccepted`)
- ✅ Регистрация: ФИО, телефон, логин, пароль, email
- ✅ Вход по логину и паролю
- ✅ Запрос разрешений: геолокация (FINE+COARSE), камера/фото
- ✅ Поиск друзей по номеру телефона, заявки в друзья, принятие/отклонение
- ✅ Согласие на передачу геолокации конкретному другу (переключатель, можно отозвать)
- ✅ Карта Yandex MapKit: свои точки со значками (📌🛒🎯🏠☕), маркеры друзей, долгое нажатие — быстрая точка
- ✅ Foreground-сервис передачи GPS на сервер с уведомлением
- ✅ Пароли хешируются, токены сессий
- ✅ Автообновление приложения: проверка версии, скачивание APK (с сервера или из GitHub Releases)
- ✅ Публичный доступ к серверу через Tailscale Funnel (автозапуск при старте Windows)

## Запуск сервера

```cmd
cd server_py
start_server.bat        # только сервер (http://127.0.0.1:9001)
start_all.bat           # сервер + публичный туннель
```

Сервер слушает порт `9001`:
- с этого же компа: `http://127.0.0.1:9001/`
- с телефона в той же Wi-Fi: `http://10.0.24.89:9001/`
- публично (через туннель): `https://atitovserv1.tailf343af.ts.net/`

## Сборка Android-приложения

1. Получите API-ключ Yandex MapKit: https://developer.tech.yandex.ru/services/
2. Пропишите ключ в `gradle.properties`:
   ```
   YANDEX_MAPKIT_API_KEY=ваш_ключ
   ```
3. Соберите:
   ```cmd
   set "JAVA_HOME=C:\Users\a.titov\Program files\android studio\jbr" && gradlew.bat assembleRelease
   ```
   Результат: `app/build/outputs/apk/release/app-release.apk`

## Раздача обновлений через GitHub Releases

Чтобы приложение скачивало APK с быстрого CDN GitHub вместо медленного домашнего
сервера, настройте GitHub Releases. Подробная инструкция — в [`GITHUB_RELEASES.md`](GITHUB_RELEASES.md).
